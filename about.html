О проекте

Neon Cosmic Games — это коллекция мини-игр в футуристическом неоновом космическом стиле. Сайт создан для развлечения и тренировки ума, реакции и памяти.

Что внутри

  • Квиз: Страны — угадай столицы мира
  • Космическая Память — классическая игра на память с космическими символами
  • Неоновый Змей — аркадный змей с неоновым свечением
  • Тест Реакции — измерь скорость своей реакции в миллисекундах
  • Математический Блиц — решай примеры на скорость
  • Цветовой Матч — не попадись на обман зрения

Рекорды

Все твои результаты сохраняются локально в браузере (session / localStorage). Они видны только тебе и исчезают при очистке данных сайта.

Технологии

Чистый HTML, CSS и JavaScript. Без фреймворков. Работает оффлайн после первой загрузки.

Контакты

Сайт размещён на GitHub Pages. Репозиторий открыт — можно форкать и улучшать.
